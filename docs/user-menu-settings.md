# ตั้งค่าเมนูผู้ใช้

หน้า `/menu-settings` ใช้บัญชี `ty@stockify.com` เท่านั้น API ตรวจบัญชีที่ยังเปิดใช้งานจากรหัสผู้ใช้ใน session ก่อนอ่านหรือบันทึกข้อมูล

เลือกพนักงาน ติ๊กเมนูที่ต้องการแสดง แล้วกดบันทึก รายการเมนูจำกัดตามบทบาทและสิทธิ์เมนูระบบเดิม เลือกทั้งหมด เอาออกทั้งหมด หรือคืนค่าเริ่มต้นได้ เมนูตั้งค่าของเจ้าของบัญชียังแสดงเสมอ

การตั้งค่านี้ควบคุมเมนูนำทางบนคอมพิวเตอร์และมือถือ สิทธิ์การทำรายการและการเปิด URL ของเมนูอื่นยังใช้การตรวจสิทธิ์เดิม เมนูที่เปลี่ยนจะอัปเดตเมื่อรีเฟรช กลับมาเปิดแท็บ หรือภายใน 60 วินาทีขณะที่แท็บเปิดอยู่

## การเตรียมที่เก็บข้อมูล

- PostgreSQL: ใช้ migration `supabase/migrations/20261013000000_user_menu_visibility.sql` ก่อนเปิดใช้งาน เพื่อเพิ่มคอลัมน์ `users.menu_hrefs` แบบ JSONB
- Google Sheets: คอลัมน์ N ของแท็บ Users ใช้เก็บ `menu_hrefs` เป็น JSON array ต้องสงวนคอลัมน์นี้สำหรับการตั้งค่าเมนู
- ค่า `null` หรือช่องว่างใน Sheets ใช้เมนูเริ่มต้นเดิม ค่า `[]` ซ่อนทุกเมนูที่เลือกได้ บัญชีเดิมไม่เปลี่ยนจนกว่าจะบันทึกการตั้งค่า
