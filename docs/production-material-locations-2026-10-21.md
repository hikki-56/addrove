# ตำแหน่งเก็บวัตถุดิบในหน้าผลิต — 21 ตุลาคม 2026

- แสดงรหัสตำแหน่งและจำนวนคงเหลือใต้ชื่อวัตถุดิบในรายละเอียดงาน หน้ายืนยันเริ่มผลิต และฟอร์มรายงานผลที่ Admin/แก้วใช้
- วัตถุดิบเดียวมีหลายตำแหน่งจะแสดงแยกทุกตำแหน่ง เฉพาะโกดัง 2 ตำแหน่งเปิดใช้งาน และยอดมากกว่า 0 แสดงจำนวนได้ถึง 3 ตำแหน่งทศนิยมตามหน่วยสต็อก
- ยอดเป็นคงเหลือจริงแต่ละตำแหน่ง การจองยังเป็นระดับสินค้า/โกดังตามระบบเดิม ไม่แสดงยอดจองทั้งโกดังเป็นยอดของตำแหน่งใดตำแหน่งหนึ่ง
- อ่านตำแหน่งเป็นข้อมูลปัจจุบันจาก `stock_summary` และ `locations` ด้วย query รวมครั้งเดียวต่อการโหลดรายการ/รายละเอียดงาน แนบไว้ใน `material_plan.stock_locations` แยกจากสูตรที่บันทึกไว้ ไม่บันทึกตำแหน่งลง BOM หรือเปลี่ยนวิธีตัดวัตถุดิบ
- ไม่พบยอดในตำแหน่งที่ใช้งานได้จะแสดง “ไม่พบสต็อก”

ตรวจแล้ว:

- ชุดทดสอบระบบผลิตและสิทธิ์ API ผ่าน 30 กรณี รวมกรณีหลายตำแหน่ง ยอดเปลี่ยนแล้วอ่านใหม่ คลังอื่นไม่ปน ตำแหน่งปิดใช้งาน/ยอดศูนย์ไม่แสดง และสูตรที่บันทึกไว้ไม่เปลี่ยน
- `npm run typecheck` ผ่าน
- Lint ของไฟล์ที่แก้ผ่าน
- ลอง component จริงใน browser ด้วยข้อมูลจำลอง ทั้งภาพรวม ก่อนเริ่มงาน และรายงานผล แสดง A1 จำนวน 15 ตัว, B2 จำนวน 5 ตัว และ C1 จำนวน 8 ชิ้นได้
