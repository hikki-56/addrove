# ผลตรวจระบบผลิต — 21 ตุลาคม 2026

## ขอบเขต

ตรวจสร้าง/แก้ไข/ลบฉบับร่าง ส่งงาน เริ่มงาน รายงานบางส่วน/จบงาน งานค้าง ยกเลิก/เปิดใหม่ สิทธิ์ Admin/ผู้อนุมัติ สูตรหลายแบบ หน่วย กำลังผลิต การจองและสต็อกโกดัง 2 การกดยืนยันซ้ำและ rollback รวมถึงชุดทดสอบเดิมทั้งแอป

การทดสอบที่เขียนใบงานหรือสต็อกใช้ PGlite แยกจากฐานข้อมูลแอป ฟอร์ม browser ใช้ component จริงกับข้อมูลจำลอง การตรวจฐานข้อมูลแอปเป็น read-only ไม่ได้ลองตัดสต็อกจริง

## ข้อผิดพลาดและการแก้ไข

- ยืนยันสาเหตุ `production_jobs_job_no_key`: ใบ `PRD-20261021-000001` ถูกลบแบบเก็บประวัติ แต่ตัวออกเลขอ่านเฉพาะใบที่ยังแสดง จึงออกเลขเดิมและชน unique constraint ทดสอบสร้าง→ลบ→สร้างซ้ำแล้วพบ error เดียวกันก่อนแก้ เปลี่ยนให้นับเลขของใบที่ลบแล้วด้วย ภายใต้ transaction และ writer lock เดิม ไม่เปลี่ยนเลขใบงานเก่า
- ครอบการลบฉบับร่างและเขียนประวัติด้วย transaction เดียวกัน
- รายงานจบงานที่ไม่มีจำนวนเพิ่มหลังรายงานบางส่วน เคยคำนวณวัตถุดิบเสมือนผลิต 1 หน่วยเพื่อตรวจสูตร ทำให้สูตรที่ต้องผลิตเป็นชุดจบงานไม่ได้ เปลี่ยนให้ตรวจยอดใช้ 0 โดยยังตรวจสูตร หน่วย และข้อมูลบังคับเดิม
- การรัน lint ทั้งโครงการเคยติดการตั้งกฎ React Hooks กับไฟล์ที่ไม่ได้โหลด plugin ปรับขอบเขตให้ตรงกับไฟล์ที่ Next.js รองรับ
- ตัวตรวจเคยอ่านสำเนาโครงการในโฟลเดอร์ `.tmp*` ที่ Git ignore ทำให้ช้าผิดปกติ เพิ่มการยกเว้นไฟล์สำเนาและ artifact ชั่วคราวใน lint/TypeScript คงการตรวจโค้ดแอปจริง
- ชุดตรวจประสิทธิภาพเดิมยังไม่รู้จักตัวเลือก storage และ transaction ที่เพิ่มในระบบ ปรับ dependency จำลองให้ตรวจ branch ที่ใช้ local lock/in-memory โดยไม่โหลดการเชื่อมต่อฐานข้อมูล และยังเรียก request wrapper จริงในชุดตรวจ progress

## กรณีตรวจสำคัญ

- สร้างงานพร้อมกัน 5 โต๊ะ เลขไม่ซ้ำ แต่ละโต๊ะจบเอง สินค้าดีและวัตถุดิบตรงตามยอดรวม และกดยืนยันซ้ำไม่ลงสต็อกซ้ำ
- ส่งหลายงานแล้วงานหลังของไม่พอ ต้องย้อนสถานะและยอดจองของชุดทั้งหมด
- มีของในคลังอื่นแต่โกดัง 2 ไม่มี ต้องผลิตได้ 0 และส่งงานไม่ได้
- สูตรต้นทางระบุคลังอื่นและสำเนาใบงานเก่าระบุคลังอื่น ยังตรวจ จอง และตัดเฉพาะโกดัง 2
- รายการวัตถุดิบซ้ำ ยอดใช้ติดลบ ของเสียไม่มีสาเหตุ ใช้ต่างสูตรไม่มีเหตุผล และตำแหน่งรับเข้าต่างโกดัง ต้องไม่เปลี่ยนสต็อก
- จำลองการรับสินค้าดีล้มเหลว ต้องย้อนรายงาน เอกสาร วัตถุดิบ และยอดจองพร้อมกัน
- สูตรที่บันทึกแล้วไม่เปลี่ยนตามต้นทาง งานค้างใช้สูตรเดียวกับงานเดิม ผู้อนุมัติไม่เห็นฉบับร่าง
- ค้นหาเฉพาะสินค้าที่มีสูตร แสดงกำลังผลิตจากตัวหลักหลังหักจอง ไม่รวมกำลังผลิตหลายสูตร และไม่เดาหน่วยที่ยังไม่ยืนยัน
