v0.2 — ล็อกทิศทางแล้ว (Q1-Q6)
1 · ปุ่ม (Buttons)
ลำดับความสำคัญชัดเจน — หน้าหนึ่งมีปุ่มหลักได้ปุ่มเดียว · ปุ่มทำลายคือพื้นขาวขอบแดง ไม่ใช่แดงทึบ
SURFACE พนักงาน (มือถือ — ปุ่มเต็มความกว้าง)
หลัก 56 / 48 / 44 px · ระยะห่าง 12px · ปุ่ม ต้องมีข้อความ ไม่ใช่ไอคอนเปล่า
SURFACE แอดมิน (เดสก์ท็อป — ปุ่มแน่นกว่า) + ปุ่มทำลาย
ปุ่มทำลาย (ลบ) = ขาวขอบแดง และวาง ห่างจากปุ่มหลัก — กันกดพลาดตาม P2 · แถวล่างคือสถานะปิดใช้งาน
2 · ฟอร์ม (Inputs)
label ผูกช่องกรอกด้วย htmlFor ทุกช่อง · ช่องสแกนห้าม disabled — ใช้ readOnly เพื่อไม่เสียโฟกัสของเครื่องยิงบาร์โค้ด
ช่องกรอกปกติ
ตัวเลขที่ต้องตรวจใช้ 20px + bold · ข้อความสำคัญ ห้ามใส่ placeholder — มันหายทันทีที่พิมพ์
ช่องสแกน (BarcodeScanInput)
กำลังตรวจ…
ระหว่างประมวลผลใช้ readOnly + aria-busy + opacity — ห้าม disabled เพราะช่องเสียโฟกัส ทำให้ยิงสแกนรัว ๆ ตกหล่น (สาเหตุ "ต้องสแกนสองครั้ง")
✓ พบสินค้า
สายถัก STL 24 นิ้ว
คงเหลือ 1,250 ชิ้น · ตำแหน่ง L1-A2
ผลสแกนต้องเด่นที่สุดบนจอ (ScanFeedbackBanner) · กรณีไม่พบต้องบอกทางออก: "ไม่พบสินค้ารหัสนี้ — สแกนใหม่ หรือค้นด้วยชื่อสินค้า"
