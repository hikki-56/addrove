# ใบงานพิมพ์สำหรับแก้ว — 21 ตุลาคม 2026

## รูปแบบปัจจุบัน

- A4 แนวตั้ง สินค้าแต่ละใบงานเริ่มคนละแผ่น เรียงวันที่ โต๊ะ และเลขใบงาน
- แสดงเลขใบงาน โต๊ะ วันที่ สถานะ สินค้า SKU บาร์โค้ด สูตร และจำนวนที่ยังต้องผลิตเหนือรายการวัตถุดิบ
- ลบแถบจำนวนสั่งผลิต/ผลิตดีแล้ว/ต้องผลิตเพิ่มตามคำขอ
- วัตถุดิบใช้สูตรที่บันทึกกับใบงานและอัตราแปลงที่ยืนยัน แสดงตำแหน่งในโกดัง 2 พร้อมยอดคงเหลือ
- ใต้ตารางวัตถุดิบทุกใบมีช่องเซ็น “ผู้ตรวจสอบ..........................” เว้นระยะ 16px และแสดงหมายเหตุถัดลงมา
- ตัวอย่างย่อให้พอดีความกว้างจอ ส่วนการพิมพ์ใช้ขนาดจริง หากวัตถุดิบยาวจะต่อหน้าโดยไม่ซ่อนข้อมูล

## การใช้งานและข้อมูล

Admin/ผู้อนุมัติกดพิมพ์ใบงานจากหน้ารายการที่กรองไว้หรือรายละเอียดรายใบ แล้วเลือกพิมพ์/บันทึก PDF
อ่านข้อมูลใหม่ผ่าน API ที่ตรวจสิทธิ์เดิมก่อนเปิดตัวอย่าง คำนวณจากยอดสินค้าดีที่ยังเหลือ พิมพ์เฉพาะงานรอผลิต/กำลังผลิตที่ยังมียอดเหลือ
ขาดสูตรหรืออัตราแปลงจะแสดงปัญหาและปิดปุ่มพิมพ์ การพิมพ์ไม่จองหรือตัดสต็อก
