# แผ่นพับสรุปขั้นตอนการทำงานด่วน (Quick Reference Card)
### ระบบคลังสินค้า Stockify — สำหรับพิมพ์ติดบอร์ดและโต๊ะทำงานคลัง

---

## 📱 1. การเข้าสู่ระบบพนักงาน (Login)
1. ใช้มือถือสแกน **QR Code หน้าประตูโกดัง**
2. กด **รหัส PIN 4 หลัก** ประจำตัว
3. เข้าสู่หน้างานทันที *(เซสชันใช้งานได้นาน 2 ชั่วโมง)*
> ⚠️ **คำเตือน:** หากกด PIN ผิดครบ 5 ครั้ง ระบบจะระงับการทำงาน 5 นาที

---

## 📥 2. การรับสินค้าเข้าโกดัง (Receive - RCV)
```
[ เมนูรับสินค้าเข้า ]
         ▼
[ สแกนบาร์โค้ดสินค้า ]  ──► (กล่องสินค้าจะเด้งขึ้นจอ)
         ▼
[ ระบุจำนวนกล่อง/ชิ้น ] ──► นับของจริงแล้วกรอก
         ▼
[ สแกนบาร์โค้ดชั้นวาง ]  ──► ยิงป้ายชั้นวาง เช่น 1K14-1A
         ▼
[ ✓ ยืนยันรายการนี้ ]  ──► กดเพื่อพับเก็บรายการ
         ▼
[ สแกนชิ้นต่อไป... หรือกด 'ตรวจสอบและบันทึกการรับเข้า' ]
         ▼
[ ยืนยันบันทึกเอกสาร ] ──► ได้เลขที่ RCV-... รอแอดมินอนุมัติ
```

---

## 📤 3. การหยิบเบิกสินค้าตามใบสั่ง (Transfer - TRF)
```
[ เมนูเบิกสินค้า ]
         ▼
[ ดูที่กล่อง 'งานที่ต้องไปเบิก' ] ──► กดปุ่ม [ ▶ เริ่มดำเนินการหยิบ ]
         ▼
[ ขั้นที่ 1: เดินไปที่ชั้นวาง ]   ──► สแกนบาร์โค้ดบนตัวสินค้าเพื่อยืนยัน
         ▼
[ ขั้นที่ 2: นำไปส่งปลายทาง ]    ──► สแกนบาร์โค้ดชั้นวางปลายทาง
         ▼
[ ส่งงานเพื่อรออนุมัติ ]        ──► แอดมินกดอนุมัติ = ตัดสต็อกทันที
```

---

## 🔄 4. การย้ายตำแหน่งสินค้า (Move - MOV)
1. เข้าเมนู **"จัดตำแหน่งสินค้า"**
2. **ขั้นที่ 1:** สแกนชั้นวางเดิม (หรือสแกนสินค้า) + กรอกจำนวนที่ต้องการย้าย
3. **ขั้นที่ 2:** สแกนชั้นวางใหม่ปลายทาง
4. กดปุ่ม **[ ยืนยันการย้าย ]** *(ย้ายตำแหน่งทันที ไม่ต้องรออนุมัติ)*

---

## 🔍 5. การค้นหาของและชั้นวางสินค้า
- เข้าเมนู **"สินค้าทั้งหมด"**
- พิมพ์ชื่อสินค้า หรือรหัส SKU หรือสแกนบาร์โค้ด
- ดูที่ช่อง **"ตำแหน่งจัดเก็บ"** เพื่อดูว่าของชิ้นนั้นวางอยู่ที่ชั้นไหน โกดังใด

## ⚠️ รหัสเอกสารและเบอร์ติดต่อช่วยเหลือ
- **`RCV-...`** = ใบรับสินค้าเข้า
- **`TRF-...`** = ใบเบิก/โอนย้ายสินค้า
- **`MOV-...`** = ใบย้ายชั้นวางสินค้า
- **`OP-...`**  = ใบสั่งผลิตสินค้าสำเร็จรูป
- **พบปัญหาหน้างานติดต่อ:** ฝ่ายไอที / ผู้ดูแลระบบคลังสินค้า
