# คู่มือสำหรับผู้ดูแลระบบและผู้จัดการคลัง (Admin & Manager Guide)
### ระบบบริหารจัดการคลังสินค้า Stockify (ฉบับครบทุกเมนู พร้อมภาพหน้าจอจริง 100%)

> **สำหรับบทบาท:** ผู้ดูแลระบบ (ADMIN) และ ผู้จัดการคลังสินค้า (MANAGER)  
> **อุปกรณ์:** คอมพิวเตอร์เดสก์ท็อป / แล็ปท็อป (ผ่าน Google Chrome / Microsoft Edge)  
> **ภาพประกอบ:** ภาพถ่ายหน้าจอจริงจากระบบ Stockify ทุกเมนู

---

## 1. การเข้าสู่ระบบผู้ดูแลระบบ (Sign In)

![หน้าจอเข้าสู่ระบบผู้ดูแลระบบ](./images/02-real-admin-login.png)
*ภาพที่ 1: หน้าจอ Sign In ของผู้ดูแลระบบและฝ่ายจัดการ*

- เปิดเว็บบราวเซอร์ Google Chrome เข้าสู่หน้าเข้าใช้งานระบบ Stockify
- กรอก **ชื่อผู้ใช้งาน / อีเมล (Username / Email)** และ **รหัสผ่าน (Password)** ของผู้ดูแลระบบ
- คลิกปุ่ม **[ Sign In ]** เพื่อเข้าสู่ระบบ

---

## 2. [เมนูที่ 1] หน้าแดชบอร์ดภาพรวมระบบ (Admin Dashboard - `/dashboard`)

![หน้าจอแดชบอร์ดภาพรวมระบบ](./images/03-real-dashboard.png)
*ภาพที่ 2: หน้าแดชบอร์ดหลัก แสดงสถิติการเคลื่อนไหว ยอดสต็อกจริง (8,268,802 ชิ้น) และสถานะคลัง*

- ตรวจสอบยอดรวมสินค้า, รายการรออนุมัติรับเข้า (Pending RCV), รายการรอเบิก (Pending TRF)
- เลือกกรองดูข้อมูลแยกเฉพาะโกดัง (wh-01 ถึง wh-06) หรือภาพรวมทุกคลัง
- ดูกราฟความเคลื่อนไหวสินค้าเข้า-ออกรายสัปดาห์

## 3. [เมนูที่ 4] การอนุมัติและตรวจสอบใบรับสินค้า (Approvals - `/approvals`)

![หน้าจอรายการรออนุมัติการรับเข้า](./images/10-real-rcv-approvals.png)
*ภาพที่ 3: รายการเอกสารรับเข้าสินค้าที่รอการตรวจสอบอนุมัติ (`/approvals`)*

1. เข้าเมนู **"อนุมัติการรับเข้า"** (`/approvals`)
2. คลิกปุ่ม **[ ตรวจสอบ ]** ที่รายการใบรับ (เช่น `RCV-20260908-0001`)
3. ตรวจสอบรายละเอียดสินค้า จำนวน และพิกัดชั้นวาง (เช่น `1K14-1A`)
4. คลิกปุ่ม **[ ✓ อนุมัติ ]** เพื่อให้ระบบอัปเดตยอดคงเหลือใน Google Sheets ทันที
5. หากตรวจพบข้อผิดพลาด สามารถคลิก **[ ✎ แก้ไขเอกสาร ]** หรือคลิก **[ ✕ ไม่อนุมัติ ]** เพื่อส่งกลับให้หน้างาน

## 4. [เมนูที่ 3] ประวัติรับสินค้าเข้าโกดัง (Receive History - `/movements/receive/history`)

![หน้าจอประวัติรับสินค้าเข้าโกดังจริง](./images/14-real-receive-history.png)
*ภาพที่ 4: หน้าจอประวัติรับสินค้าเข้าโกดังย้อนหลัง (`/movements/receive/history`)*

- ตรวจสอบสถานะการอนุมัติ รายการสินค้า และชื่อพนักงานผู้รับสินค้าหน้างาน
- พิมพ์รายงานสรุปการรับสินค้าเข้าโกดัง

## 5. [เมนูที่ 5] การสร้างใบเบิกสินค้า (Transfer Request - `/movements/transfer`)

![หน้าจอแอดมินสร้างใบเบิกสินค้า](./images/05-real-transfer-admin.png)
*ภาพที่ 5: หน้าจอการสร้างรายการเบิกสินค้าใหม่ของแอดมิน*

1. เข้าเมนู **"เบิกสินค้า"** เลือกแท็บ **"สร้างใบเบิกสินค้า"**
2. เลือก **โกดังต้นทาง** และ **โกดังปลายทาง**
3. ค้นหาสินค้า และระบุจำนวนที่ต้องการเบิก (ระบบจะแสดงยอดคงเหลือจริงเพื่อป้องกันการเบิกเกิน)
4. คลิกปุ่ม **[ สร้างรายการเบิกสินค้า ]** เพื่อส่งงานเข้าคิวของพนักงานคลังต้นทางทันที

## 6. [เมนูที่ 6] ประวัติเบิกสินค้า (Transfer History - `/movements/transfer/history`)

![หน้าจอประวัติเบิกสินค้าจริง](./images/23-real-transfer-history.png)
*ภาพที่ 6: หน้าจอประวัติการเบิกและโอนย้ายสินค้าระหว่างคลัง (`/movements/transfer/history`)*

- ตรวจสอบสถานะการดำเนินงานของแต่ละใบเบิก TRF (กำลังเบิก / รออนุมัติ / เสร็จสมบูรณ์)
- ตรวจสอบรายละเอียดสินค้า พิกัดต้นทาง และพิกัดปลายทางที่จัดเก็บ

## 10. [เมนูที่ 10] การสั่งผลิตสินค้าตามสูตร BOM (Production - `/production`)

![หน้าจอสั่งผลิตสินค้าจริง](./images/18-real-production.png)
*ภาพที่ 10: หน้าจอสั่งผลิตสินค้าและคำนวณวัตถุดิบตามสูตร BOM (`/production`)*

1. เข้าเมนู **"สั่งผลิตสินค้า"** (`/production`)
2. เลือกสูตรการผลิต (BOM) ที่ต้องการประกอบ
3. ระบุจำนวนชุดที่ต้องการผลิต ระบบจะตรวจสอบสต็อกวัตถุดิบในโกดัง 2 โดยอัตโนมัติ
4. คลิกปุ่ม **[ สร้างคำสั่งผลิต ]** (`OP-...`) และเมื่อฝ่ายผลิตดำเนินการเสร็จสิ้น ให้กดยืนยันเพื่อตัดยอดวัตถุดิบและเพิ่มยอดสินค้าสำเร็จรูปเข้าคลัง
